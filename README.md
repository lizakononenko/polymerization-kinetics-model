# polymerization-kinetics-model
Numerical simulation of polymerization kinetics using Python and ODEs

## About the project

The project simulates polymerization kinetics using a system of ordinary differential equations (ODEs). The model describes the evolution of monomer conversion, molecular weight, and crosslink formation during polymerization.

The system is solved numerically using the BDF method from SciPy.

## What is studied

- monomer conversion over time
- number-average molecular weight (Mn)
- weight-average molecular weight (Mw)
- crosslink formation
- influence of kinetic parameters
- influence of initiator concentration

## Technologies

- Python
- NumPy
- SciPy
- Matplotlib
- Numerical methods
- Mathematical modeling

## Run

Install dependencies:

pip install -r requirements.txt

Then run:

python polymerization_kinetics_model.py

This project was developed as part of my work with mathematical modeling
